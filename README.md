# Data Analytics Task 2

## About the Project
In this project, I worked on Exploratory Data Analysis and Business Intelligence using the SuperStore dataset. I used Excel to analyze the dataset, create charts, perform business analysis, and understand sales and profit trends.

## Tools Used
- Excel
- SQL
- Pivot Tables
- Charts and Visualizations

## Work Done in This Project
- Performed Exploratory Data Analysis
- Created Pivot Tables and Charts
- Wrote SQL Business Queries
- Performed Multivariate Analysis
- Created Scatter Plots and Heatmap
- Designed a Static Dashboard

## Insights
- Technology category generated the highest sales
- Different regions showed different profit trends
- Higher sales generally resulted in higher profit
- Higher discounts sometimes reduced profit

## Outcome
This project helped me improve my understanding of data analysis, visualization, dashboard creation, and business insights using Excel and SQL.
